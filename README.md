# 🪐 Outpost Red

*A Mars survival simulator that teaches real engineering trade-offs.*

Built for the *NASA Space Apps Challenge 2026. Challenge: *Build a Junior Astronaut Mission Trainer.

## About

Space STEM content often oversimplifies real engineering trade-offs, or makes them too complex for young learners. In *Outpost Red, students become chief engineer of a four-person Mars outpost and balance **power, life support, shielding and food* for 15 sols (Martian days). A weak system drags down the others, just like on a real mission.

## How to play

1. Each sol you get *6 work points. Spend them with the *+* and *−** buttons.
2. Systems wear down every sol. Each point restores 10%.
3. Read the *forecast* to see the next event, then press *End sol*.
4. Earn 1 credit per sol. Upgrades cost 5 credits, so pick three of four.
5. Survive *15 sols* to win. If crew health reaches 0, the mission fails.

Low power also drains air and food, so power is the system everything else depends on.

## NASA science used

| Game event | Real NASA basis |
|---|---|
| 🌪️ Dust storm | Opportunity rover went silent in 2018 after a huge dust storm |
| ☀️ Solar flare | Mars has no global magnetic field and a thin atmosphere |
| 🔧 Scrubber failure | ISS systems remove CO₂ from the air |
| 🦠 Crop blight | Crops grown on the ISS with NASA's Veggie system |

## Tech

HTML, CSS and JavaScript in a single file. No install and no frameworks. Works on phones and laptops.

## Run it

Download or clone this repository and open index.html in any browser.
